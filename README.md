# Encoding Strategies Memory Experiment

A static browser-based psychology experiment built with plain HTML, CSS, and JavaScript.

## Run locally
1. Keep `index.html`, `styles.css`, and `script.js` in the same folder.
2. Open `index.html` in a modern web browser.
3. Complete the experiment and download both CSV files from the results screen.

## Publish with GitHub Pages
1. Create a **public** GitHub repository (for example, `encoding-demo`).
2. Upload the three project files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. After deployment, open the Visit site link.

## Experiment details
- Three encoding strategies: maintenance rehearsal, self-reference, and mental imagery.
- Six concrete words per strategy.
- Strategy order and word-list assignment are randomized each session.
- 30-second backward-counting distraction task.
- Free recall and strategy-specific scoring.
- Summary CSV (one session row) and trial-level CSV (18 word rows).

## Data and privacy
This practice version does not transmit or centrally collect participant data. Session data stays in the browser until the page is closed; participants can download CSV files to their own device. Do not put participant data, credentials, or sensitive information in a public GitHub repository.
